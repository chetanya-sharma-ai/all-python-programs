# All Python Programs

A sequenced collection of Python practice programs for students. The examples progress from getting started and control flow to small algorithms, functions, collections, modules, file handling, and CSV.

## Learning path

Work through the numbered folders in order. Each program is a small exercise. Read its source, predict the output, run it, then change one input or rule and run it again. The original program files and source code are preserved.

## Setup and run

1. Install Python 3 from https://www.python.org/downloads/ and enable the option to add Python to your PATH.
2. Clone or download this repository.
3. Open a terminal in the folder containing the example you want to run.
4. Run a program with:

~~~~bash
python "program name.py"
~~~~

On some systems, use python3 instead of python. Most examples read values from the keyboard. File and CSV examples read or write sample files in their current working folder. Keep experiments in a copy of the sample data.

No third-party packages are required. Examples use the Python standard library.

## Student revision tips

- Keep a notebook of the concept, input, expected output, and actual output for each exercise.
- Trace loops one iteration at a time and write down how each variable changes.
- Solve a small example by hand before translating the steps into Python.
- Re-run programs with boundary cases such as zero, one, repeated values, and values in a different order.
- Compare related implementations, such as for versus while or iterative versus recursive factorial.
- Explain each line in your own words before using an example as a revision reference.

## Contribution guidance

Students are welcome to contribute focused examples and corrections.

1. Place each example in the most relevant numbered topic folder.
2. Use a short, descriptive filename and include a brief comment explaining the goal.
3. Keep examples beginner-friendly and self-contained. Avoid external dependencies unless the topic requires them.
4. Include sample input/output in the pull request description when behavior is not obvious.
5. Do not include credentials, private student records, or other personal data in code or sample files.
6. Check that file examples use relative paths and explain any sample files they need.

## Repository contents

The numbered folders are the learning path. Sample data files are kept with the related file or CSV examples. Generated Python bytecode and cache folders are not included. These are original practice exercises; review each program before running it, since some may contain classroom typos or demonstrate file and directory operations.
